Token Launch Radar is a deterministic offline analytics engine that scores pre-token DeFi protocols from DefiLlama snapshots using TVL, 7-day growth, and protocol age to construct a ranked implied value board and actionable multi-step farm plans.

## Run it

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input /input/snapshot.json
```

The sealed snapshot lives at /input/snapshot.json in the grader; pass any local copy with --input.

## Dashboard

The static web dashboard is located in `dashboard/` and reads `out/data.js` generated by the radar. Open `dashboard/index.html` in any browser or serve statically to explore the ranked board, filter by category and chain, inspect individual protocol score breakdowns and generated farm plans, and experiment with model constants in the model sandbox.
