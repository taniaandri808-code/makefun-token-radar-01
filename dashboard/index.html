Methodology & Implied Value Model

Token Launch Radar is a deterministic offline analytics engine that scores pre-token DeFi protocols from DefiLlama snapshots using TVL, 7-day growth, and protocol age to construct a ranked implied value board and actionable multi-step farm plans.

Base Valuation

Base = TVL × Base Multiple (0.25). Represents foundational capital scale.

Growth Multiplier

Growth = Clamp(7d Change, -60%, 120%). Growth Multiplier = 1 + (Growth / 100) × 0.5.

Maturity Multiplier

Maturity = 0.6 + min(Age, 1095) / 1095 × 0.4. Rewards proven protocol history.
